# ⚙️ dotfiles

Personal configuration files for setting up a consistent and reproducible development environment.

This repository contains my shell setup, package management configuration, and development tools—allowing me to bootstrap a fresh machine in minutes.

---

## 🚀 Features

- 🔧 Automated setup using shell scripts
- 📦 Package management via Homebrew (`Brewfile`)
- 🐚 Zsh configuration with custom aliases and tools
- 💻 Developer-focused environment (Node.js, Git, etc.)
- 🔁 Easily reproducible setup across machines

## 🛠️ Installation

Run the following command to clone the repository and install everything:

```bash
git clone https://github.com/IsaacUA/dotfiles.git ~/.dotfiles && cd ~/.dotfiles && ./install

```

## ⚠️ Disclaimer

This is my personal development environment setup.
It is tailored to my workflow and preferences, and may not suit everyone’s needs.
Feel free to use it as a reference or starting point, but review and adapt it before using it on your own system.
